# 核桃记账功能修复与验证记录

本次是联网记账流程修复，不是原生产品整体交付。基线为本地 bcb52fe。未部署 Cloudflare，未修改或删除线上数据；旧 IndexedDB 数据保留，尚未迁移。

## 已实现的修复

- 金额：保存结算加减表达式、连续运算、输入位数限制、整数分值校验；日期按设备本地日历分组。
- 分类：独立管理页，支出/收入切换、新增、名称/图标/颜色编辑、排序、归档、一键添加常用分类；真实 API 持久化，旧账单保留已归档分类引用。
- 记账：真实账本/分类/账户 ID、日期和备注编辑、收入、支出、双账户转账；保存成功后才提示已保存到云端；保存期间互斥，网络结果未知时冻结原请求并用原幂等键重试。
- 账单：当前授权账本的云端记录、月份和文字筛选、真实收支汇总、金额/日期/备注编辑、确认删除及版本冲突提示。
- 账户：真实余额和净资产、新建账户与期初余额、归档、进入转账。
- 统计：真实记录产生时段汇总、每日支出与分类占比；本月、上月、今年、自定义日期；自定义跨年不合并同月同日。
- 月预算：按账本和月份读取/保存，所有者管理、版本校验；账单显示真实预算使用和超支。
- 共享账本：创建/切换、成员列表、邀请码生成、预览后加入、角色切换、确认移除与所有权移交。
- 会话与设备：Web 会话在同一标签页刷新后恢复，令牌过期刷新重试；真实设备列表、确认撤销、退出登录。
- 数据导出：当前账本 CSV 和 JSON 数据副本；CSV 含转账双方账户 ID/名称，并转义引号、换行和公式前缀。CSV 可用 Excel 打开，但不是 .xlsx 导出。JSON 不是完整数据库备份，不包含已归档资源、设备或权限等全部数据。
- 移动页面入口补 viewport。实际手机布局及安全区域尚未验收。

## 审查发现并修复的后端问题

1. 旧同步写入允许通过冲突 ID 覆盖其他账本交易，还绕过账户流水维护。已移除不安全的写入实现，并让已鉴权的 `POST /sync/push` 返回 `503 SYNC_NOT_AVAILABLE`。这不是完整同步实现；联网交易接口独立可用。
2. 并发编辑/删除先检查版本再无条件改账户流水，可能造成账单与余额不一致。现在账户流水变更与账单版本推进在同一 D1 原子批处理中使用同一版本条件，失败方返回 409。
3. 账户及分类名称关联查询增加 `ledger_id` 边界。

修复代码尚未部署，因此以上安全修复尚未作用于线上 Worker。

## 浏览器验证受阻

Chromium 安装多次超时或返回 HTTP 502；浏览器脚本在启动前退出 2，记录 `status: blocked`，没有生成手机截图，也没有通过视觉验收。

`scripts/audit-mobile.cjs` 已更新为隔离数据的浏览器测试：模拟 API，不连接生产后端，执行键盘保存、分类新增/改名/归档，检查 390px/320px 页面溢出并保存截图。脚本语法通过，但完整浏览器执行尚未验证。

## 未完成及不能宣称可用的部分

- 原生 SQLite、Keystore/Keychain、Android/iOS 安装包和真机测试。当前 sessionStorage 仅为 Web 同标签页会话持久化，不是原生安全存储。
- 离线新增/编辑/删除、Outbox 上传、增量同步闭环、冲突解决、后台恢复同步。旧同步写入已主动关闭。
- 旧版本机记录缺少可靠用户/账本归属，未自动迁移，也未删除；不能不经确认混入某个用户的云账本。
- 标签与消费成员关联；当前快捷栏显示账本选择，不宣称已实现消费成员功能。
- .xlsx 导出、完整备份恢复、R2 与线上备份验收。
- 导入、周期账单、借贷、图片等原设计后续功能。
- 万条数据性能、真实两用户跨设备操作和线上 Cloudflare 部署验收。当前统计会分页读取当前账本全部交易后本地汇总，尚未满足万条性能目标。

## 本地验证命令

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm typecheck
pnpm build
pnpm exec playwright install chromium --only-shell
pnpm --filter @walnut/mobile test:visual
```

浏览器证据默认输出 `/tmp/walnut-mobile-audit`，可通过 `AUDIT_OUTPUT` 指定目录。浏览器启动失败应保持非零退出状态，不得跳过后标绿。

## 部署边界

本次未新增数据库迁移，预算使用既有 budgets 表。前后端必须配套更新：分类编辑/批量添加、收入 kind、账户余额字段及月预算需要新的 Worker API。不要只发布前端而继续使用旧 API。
